Discovery

FAQ

Process
Questions

Common questions about how we work, timelines, and what you can expect when you partner with Automora.

Start a Project ↗
How long does a typical project take?
+
A typical web development project takes 4–6 weeks from kickoff to launch. AI automation and chatbot projects vary based on complexity — usually 3–6 weeks. We provide a detailed timeline during the strategy phase, so there are no surprises.
How involved will I be in the process?
+
As involved as you want to be. We recommend regular check-ins at each phase — typically weekly calls or async updates. You'll review wireframes, designs, and development progress at each stage. We use transparent project management tools so you can track progress anytime.
What technologies do you use?
+
We use modern, battle-tested technologies: React, Next.js, TypeScript, Node.js for web apps; Python, GPT-4, LangChain for AI solutions; AWS, Vercel, Docker for infrastructure. We select the best tech stack for each project's specific needs. Our full technology stack is detailed on the Technologies page.
Do you provide post-launch support?
+
Absolutely. We offer monthly retainer packages for ongoing maintenance, security updates, content changes, performance monitoring, and SEO optimization. Most of our clients continue working with us long after launch for this reason.
How do you handle changes during development?
+
We build flexibility into our process. Minor changes are accommodated within the project scope. For significant scope changes, we discuss them openly, adjust the timeline and budget if needed, and ensure you're fully informed before proceeding.
